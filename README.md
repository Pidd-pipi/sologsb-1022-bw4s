# 稽古堂 · 丛书分卷整理台

面向公版古籍**丛书分卷整理**的指路式互见工作台。互见不再是照抄的一句文字，而是一条可核对的“指路关系”：记到**哪一卷、哪一章、哪一句**；章节调序、句子挪章后，互见地址与脚注编号统一重算，指不到目标的一律保留为待办。

## 核心约定

- **互见 = 指路关系**：每条互见保存起点句与目标句的稳定 ID，人读地址（《卷》· 章 · 第 N 句）只在重算阶段生成。
- **改动即重算**：改字、章序调整、整章移卷、句子挪进别章后，`recompute` 统一刷新互见地址与章内脚注号；阅读、校勘、检索、导出都只消费重算结果。
- **指不到就留待办，绝不猜**：目标句被删/挪失时互见标记为“指空”，失附脚注进待办；记录本身不被悄悄抹掉，可随时“重指目标”。
- **旧稿迁移**：照抄文字的旧互见按引句在现稿中唯一定位后转指路；**没记卷册**、引句对不上或重出不唯一的，统一进“待认领处”，由整理者选定起点句与目标句后认领。
- **多人分卷 + 会校**：整理者各自带底本（base）开工作分支；写回时做三方比对，只有一边动过自动并入，**同一处互见两边都动过（含一删一改）则并排摆出**，由总校选定版本后写回。
- **写回失败可重试**：模拟接口 503 时 trunk 不动、分支工作稿与原稿 base 原样保留，接口恢复后“从原稿重试”。

## 三视图

- **阅读版**：按重算后的卷章次序展示；脚注带章内连续编号，互见是可点击的卷/章/句指路，可直接跳到目标句。
- **编辑版**：改字、句上移/下移、句子挪到别卷别章、整章移卷、追加句/章/卷；保存即触发重算。
- **校勘版**：逐句列异文、互见地址与“他处互见至此”，指空标红、待认领标黄。

## 其他功能

- 左侧卷册目录跳转 + 全文检索（正文/脚注/互见地址，全部来自重算结果，命中带卷章句地址）。
- 右侧校理面板：互见（建立/改指/重指）、注记（脚注占号、异文不占号）、待办、会校、旧稿迁移、导出。
- 旧稿批量导入语法：
  - `互见 从=起点引句 -> 目标引句 @ 卷名`（省略 `@ 卷名` 即“没记卷册”，直接待认领）
  - `注 句=所附注引句 | 标题=… | 正文=… | 来源=…`
- 导出：阅读版 HTML（含互见指路表与待办清单）、校勘版 HTML、核对用 JSON（原始稳定 ID + 重算视图）。
- 快捷键：`Alt+1/2/3` 切换视图，`/` 聚焦检索；离线草稿自动存入 localStorage。

## 目录结构

```
lib/series/
  types.ts       领域模型（卷/章/句、互见、注、待办、分支、会校冲突）
  engine.ts      recompute：排序、卷章句地址、互见核对、脚注重编号、待办、检索
  structure.ts   结构变更（改序、挪句、移章、删除；稳定 ID 不变）
  annotations.ts 互见/注的增删改（只接受显式卷章句目标）
  migration.ts   旧稿迁移：引句唯一定位转指路，否则待认领
  merge.ts       开分支、三方比对、写回、失败重试、总校裁定
  export.ts      阅读/校勘 HTML 与核对 JSON（只吃重算结果）
  seed.ts        三卷示例底本 + 旧稿迁移演示（含指空、待认领样例）
  store.ts       useReducer 状态、localStorage 持久化
components/series/  工作台 UI
scripts/selftest/   46 项领域逻辑自测（无测试框架，tsc + node）
```

## 本地开发

```bash
npm install
npm run dev
```

## 生产构建

```bash
npm install
npm run build      # 静态产物在 out/
npm run selftest   # 逻辑自测：重算/重编号/待办/迁移/会校/失败重试
```

## Docker

```bash
docker build -t jigutang-series .
docker run --rm -p 10022:80 jigutang-series
```

## 数据说明

工作底本、工作分支、会校队列与未写回的工作稿都保存在当前浏览器 `localStorage`；右侧“导出”页签可重置回内置底本。导出的 JSON 同时包含稳定 ID 原始数据与重算视图，便于外部系统核对。
