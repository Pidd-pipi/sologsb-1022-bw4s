# 稽古堂 · 丛书互见整理台

面向公版古籍**丛书分卷整理**的工作台。互见不再照抄文字，而是一条条可核对的“指路关系”；章节次序一调，互见指向与脚注编号整体重算，指不到目标的留成待办。支持多位整理者同时编辑不同卷册、总校并排定夺后写回，以及旧稿迁移与待认领。

## 核心约定

- **互见 = 指路关系**：每条互见写明通向“哪一卷 · 哪一章 · 第几句（或句内词语）”，并留存建立时的目标原文用于核对。
- **稳定 ID + 整体重算**：句子在章内移动、挪到别章、章序调整都靠稳定句子 ID 跟随；每次改动后，互见状态（已核对 / 引文漂移 / 待办）与各章脚注连续编号全部重算。
- **指不到就留待办**：目标句子缺失、章卷对不上、旧稿未记卷册，互见自动标红列待办，可在待办页“补指目标”销账。
- **阅读 / 校勘 / 检索 / 导出统一按重算结果**呈现：正文角标、脚注号、全文检索、HTML/JSON 导出用的都是同一份重算稿面。

## 功能

- 卷 → 章 → 句三级目录与跳转；句子可上移/下移（可跨章）、可修订正文；词级引用落空时自动迁移到所属句。
- 句级/词级脚注按“句序、句内词序”在章内连续编号；异文、背景说明不占脚注号。
- 互见角标显示“卷·章·第几句”，点击直达；目标被改写时提示“引文漂移”，并列新旧文。
- 待办面板：落空互见补指销账；**旧稿迁移**按行解析卷次/章题，没记卷册或对不上章的整段进“待认领处”，照抄的“见/参见/互见……”转为指路关系。
- 待认领片段可由总校认领入指定卷章（或新建章）。
- 多位整理者各自开**工作副本**编辑不同卷册：同一处互见两边都动过时，在“总校”页左右并排摆出，由总校择定一侧再写回；未拍板不覆盖底本。
- 写回模拟失败时**原稿保留、底本不动**，可“从原稿重试”；写回后整体重算。
- 来源冲突（同目标同类型异文）逐条选用来源解决。
- 全文检索覆盖正文、注释、来源与互见指路，待办结果以红色区分。
- 离线草稿（localStorage）、校订快照、导出 HTML 阅读版 / JSON。
- 快捷键：`[`/`]` 上/下句，`/` 聚焦搜索，`Alt+1/2/3` 切视图，`Ctrl/⌘+Z` 撤销，`Ctrl/⌘+Shift+Z` 重做，`Ctrl/⌘+S` 保存。

## 技术栈

- Next.js 15（App Router、静态导出）、React 19、TypeScript、HeroUI + Tailwind CSS
- 纯前端，无后端：重算引擎见 `lib/recompute.ts`，写回/冲突见 `lib/merge.ts`，旧稿迁移见 `lib/migrate.ts`

## 本地开发

```bash
npm install
npm run dev
```

## 生产构建

```bash
npm run build   # 静态产物在 out/
```

## Docker

```bash
docker build -t sologsb-1022 .
docker run --rm -p 10022:80 sologsb-1022
```

## 数据说明

离线草稿、工作副本、快照保存在当前浏览器 `localStorage`；清除站点数据会删除这些内容，可用导出的 HTML/JSON 备份。
